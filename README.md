# Product Catalog Service

This repository contains a Spring Boot backend and a Next.js frontend:

- [`backend/`](./backend/) — Spring Boot REST API and Maven project. See [`backend/README.md`](./backend/README.md) for setup and API details.
- [`frontend/`](./frontend/) — Next.js App Router UI with Tailwind CSS, connected to the backend API.

For frontend setup and API integration details, see [`frontend/README.md`](./frontend/README.md).
